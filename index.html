4 Track Information by Song Recognition Service
How Song Recognition Works

A short audio sample from the middle of each track is fingerprinted or sent to the selected service. If the song is recognised, its title, artist, album and year are filled in automatically.

Shazam via RapidAPI — sign up at RapidAPI ↗ and subscribe to the Shazam API. Uses an unofficial endpoint.

AcoustID — open, free fingerprinting service backed by MusicBrainz. Computes a Chromaprint fingerprint locally (~60 s of audio), submits to AcoustID, and looks up full metadata from MusicBrainz. Get a free API key at acoustid.org ↗. Loads the Chromaprint.js library (~120 KB) from CDN on first use.

AudD — sign up for a free key at dashboard.audd.io ↗.

Your API key is never stored — it lives only in the page for the duration of your session. Use Identify All/Selected Untagged to process every untagged track, or tick checkboxes in the Review card to target specific tracks.

6 Export Tracks
Export Options

ZIP (MP3): Converts tracks to MP3 directly in your browser using MediaBunny. Creates a ZIP file with fully-tagged MP3s. No external software needed.

ZIP (FLAC): Converts tracks to FLAC directly in your browser. Creates a ZIP file with lossless FLAC files and metadata.

ZIP (WAV): Exports each track as WAV files in a ZIP. Use Mp3tag or Kid3 to add ID3 tags afterwards.

FFmpeg Script .sh (macOS/Linux): Place in the same folder as your audio file, run chmod +x script.sh && ./script.sh. Produces fully-tagged MP3s. Get FFmpeg ↗

FFmpeg Script .bat (Windows): Place in the same folder as your audio file, then double-click or run from a command prompt. Requires FFmpeg on your PATH.

Cue Sheet: A single .cue file describing all split points — use with your audio player or ripper.

Metadata JSON: A structured JSON file with all track metadata for use in custom workflows.
